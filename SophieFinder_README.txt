SOPHIE FINDER v1.0 — Roblox in-game GUI prototype

This file is a LocalScript for Roblox Studio, for an experience you control or
have permission to modify. It is not a Chrome extension or Luarmor loader.

TEST IN ROBLOX STUDIO
1. Open an experience you control in Roblox Studio.
2. In Explorer, open StarterPlayer > StarterPlayerScripts.
3. Insert a LocalScript, paste SophieFinder_v1.lua into it.
4. Click Play (not Run). The draggable Sophie Finder panel appears.
5. Try minimum income, rarity cycling, and sorting.

CURRENT LIMITATIONS
- The three entries are labeled SAMPLE DATA and are not real live sightings.
- Join Best is intentionally disabled because no verified server IDs exist.
- No third-party protected code is copied or decrypted.
- No automatic scanning or teleportation occurs.
